# Frontend

React 19 single-page app: TypeScript (strict), Vite, TanStack Router and Query, Tailwind CSS v4, shadcn/ui on Base UI. Explanations for people: [README.md](README.md).

## Commands

Run them in `frontend/`. Use pnpm only, never npm or yarn (the lockfile is `pnpm-lock.yaml`).

- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`: all four must pass (CI runs them).
- `pnpm format`: fixes formatting with Prettier, including the order of Tailwind classes.
- `pnpm dev`: <http://localhost:5173>; `/api`, `/oauth2`, `/login` and `/logout` are forwarded to the backend on :8080.

## Structure

- `src/routes/`: one file per page (TanStack Router, file-based). Route files stay thin and render a component from `src/features/`.
- `src/features/<feature>/`: the components, hooks and tests of one feature (booking, my-appointments, staff-calendar, …).
- `src/shared/ui/`: shadcn/ui components. They are our code and may be changed. Add one with `pnpm dlx shadcn@latest add <name>`, then check `git status`: new files must be in `src/shared/ui/`, nowhere else.
- `src/shared/lib/`: small helpers such as `cn()`. Import from `src` with the `@/` alias.
- Generated, never edited by hand: `src/app/routeTree.gen.ts` (rewritten by `pnpm dev` and `pnpm build`; commit it together with route changes) and later `src/api/` (orval).

## Rules

- Server data only through TanStack Query (later through hooks generated by orval). No global store, no `fetch` inside `useEffect`.
- No tokens or user data in `localStorage` or `sessionStorage`: the backend keeps the session in a cookie.
- Dates and times are shown in the salon's time zone (from the salon settings, `Europe/Warsaw` by default), not the browser's.
- Text that users see is in Polish; identifiers and comments are in English.
- Styling with Tailwind classes and theme colors (`bg-background`, `text-muted-foreground`, …). No fixed colors and no inline styles. Combine classes with `cn()`.
- Accessibility: jsx-a11y (strict) must pass. Use semantic elements (a `button`, not a clickable `div`), give every form field a label and every image an `alt`.
- TypeScript: no `any`, no `@ts-ignore`, and no `!` to silence an error. `noUncheckedIndexedAccess` is on, so handle the `undefined` case.

## Tests

- Vitest and Testing Library; test files sit next to the code (`*.test.tsx`).
- Query elements the way a user finds them (`getByRole`, `getByLabelText`), not by CSS classes or test IDs. Assert what the user sees.
- [`src/app/App.test.tsx`](src/app/App.test.tsx) shows how to render the whole app at a given address.
