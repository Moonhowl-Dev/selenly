# Frontend

React single-page app with three areas: public pages, the client area and the staff/owner panel.

**Not created yet.** The project skeleton is set up in [#6](https://github.com/Moonhowl-Dev/selenly/issues/6).

Planned:

- React 19, TypeScript (strict), Vite, pnpm
- TanStack Router and TanStack Query, Tailwind CSS v4, shadcn/ui
- API client generated from OpenAPI with orval (`src/api/`, never edited by hand)
- Tests with Vitest, Testing Library, MSW and Playwright
